## 1. 功能定位

面向移动端图片、短视频素材，提供轻量、快速、无痕的字幕消除能力。支持：

- 规则/Vision/可选 CoreML 自动检测 + 手动框选/涂抹微调
- 手动涂抹精准消除 + 橡皮擦/撤销/重置/画笔粗细
- 图片与 1080P 及以下短视频处理
- 纯端侧处理，无网络请求，日志不含画面内容
- 独立全屏页面，完整返回闭环，无死页面
- 仅处理硬字幕；软字幕轨不处理

适配场景：手机端日常素材修图、二次剪辑、短视频去字幕预处理。

支持上限建议：
- 图片最大长边 4096px，超过下采样后处理。
- 视频建议 ≤1080P、≤3 分钟；超限提示裁剪或降低规格。
- 透明图、HEIC/PNG/JPEG、横竖屏、可变帧率视频需兼容。

## 2. 核心目标

1. 性能可控：固定基准设备下的处理耗时、内存峰值、CPU/GPU 占用可测；杜绝 OOM、闪退、画面撕裂。
2. 效果最优：解决字幕边缘残留、背景断层、模糊虚化、视频闪烁、接缝。
3. 交互闭环：导入校验、检测、编辑、执行、取消、预览对比、二次微调、重置、导出、返回完整闭环。
4. 工程规范：SwiftUI + MVVM，独立导航栈，模块解耦，错误码统一，任务可取消，可测试。
5. 兼容性强：iOS 16+、横竖屏、透明图、不同分辨率、动态字幕、可变帧率视频、音频/方向/色彩空间。
6. 可降级：低端设备自动关闭重 AI 检测、降低预览分辨率、降低并发，优先保证稳定。

## 4. 优化后交互流程

导入图片/视频
→ 校验素材、权限、空间、方向、时长、分辨率
→ 进入独立全屏字幕消除编辑页
→ 模式选择：默认自动模式，可切手动涂抹
   【自动模式】
   规则/Vision/可选模型检测字幕区域
   → 智能框选 + 高亮展示
   → 支持拖动/缩放/多选区微调
   → 视频支持关键帧检测 + 时域跟踪，避免逐帧误检
   【手动模式】
   画笔涂抹字幕区域
   → 橡皮擦、撤销、重置、画笔粗细调节
   → 轨迹平滑采样、抗锯齿、归一化坐标存储
→ 执行前显示 mask 覆盖预览
→ 一键【执行消除】
→ 进度条 + 可取消
→ 双指缩放预览 + 左右滑动原图/修复图对比
→ 支持二次微调选区/重绘消除、一键重置原图
→ 确认后导出：图片保存相册；视频保留音频/方向/色彩后保存
→ 左上角返回按钮 + 受控边缘左滑返回
→ 处理中返回需二次确认并取消任务，清理帧池/临时文件/writer

手势优先级：
1. 画布内单指涂抹优先；双指缩放次之。
2. 左边缘 20pt 区域不响应涂抹，仅用于受控返回手势。
3. `processing/exporting` 状态禁用手势与执行按钮。
4. 全屏页不依赖系统默认边缘返回；使用 GestureCoordinator 仲裁。
5. `fullScreenCover` 使用 `.interactiveDismissDisabled(processing || exporting)`，处理中禁止下滑关闭。

## 5. 技术架构

| 层级 | 方案 | 关键说明 |
|---|---|---|
| 字幕检测层 | 规则优先：底部安全区；Vision 文本矩形兜底；可选 CoreML 增强 | 模型不可用/低端设备自动降级；检测结果可编辑；视频关键帧检测+跟踪 |
| Mask 生成层 | 手绘轨迹平滑采样 + 归一化坐标 + 相对膨胀 + 羽化 + 抗锯齿 + 多 mask 合并 | 分辨率无关；画笔 pt 转图像像素；视频 mask 时域并集受限 |
| 图像修复引擎 | OpenCV Telea 局部修复为主；大面积启用重叠 halo + 接缝融合 + 纹理增强降级 | 无 mask 区域不动；透明图单独处理 alpha |
| 视频处理管线 | AVFoundation 逐帧读取 + 源 PTS 对齐 + 帧池限流 + 背压 + 流式 AVAssetWriter 导出 | 不缓存全视频；保留音频/方向/色彩；损坏帧跳过并记录 |
| 视频元数据层 | `VideoMetadataService` | 统一正方向坐标；保留 transform、音频轨、VFR；HDR 明确降级 |
| 渲染展示层 | SwiftUI + Metal 轻量画布/预览代理 | 画笔与预览流畅；全质量结果后台生成 |
| 导航架构 | `fullScreenCover` + 内部 `NavigationStack` | 独立导航栈；受控边缘返回与画布手势隔离 |
| 状态与容错 | `StateMachine + ErrorCode + Task 取消` | 非法状态拦截；所有异步任务可取消；异常不闪退 |
| 临时文件 | `TemporaryFileManager` | 取消/失败/完成均清理；导出前检查存储余量 |
| 调试能力 | DEBUG 专用 DebugPanelView / DebugOverlayView | Release 不包含入口与敏感日志 |

核心技术优化点：
1. 字幕区域 < 画面 20% 局部修复；≥20% 启用重叠瓦片/分块修复，瓦片带 halo 与接缝融合。
2. Mask 膨胀按分辨率相对化：1080P 默认 2~4px 或字幕高度 10~20%；羽化 1~2px@1080P。
3. 视频 mask 前后帧并集默认 ±1~2 帧；场景切换清空跟踪与并集，防拖影过修。
4. UI 主线程，计算后台；OpenCV 调用串行/受限并发；视频处理背压控制。
5. 编辑与对比使用低分辨率代理，最终导出全质量。
6. 自动检测降级：规则 → Vision → 可选模型；失败提示手动涂抹，不阻塞主流程。

## 6. 关键实现细节

### 6.1 导航与手势
- 全屏页使用 `fullScreenCover`，内部独立 `NavigationStack`。
- 左上角返回按钮始终可见；处理中返回弹二次确认。
- 受控边缘返回：左边缘 20pt 的 DragGesture，仅 `editing/previewing/completed/failed` 可用。
- GestureCoordinator 状态：`idle / drawing / pinching / edgeReturn / disabled`；同一时刻仅一个手势生效。
- 处理中禁用画布、执行、导出、返回手势，仅允许取消。

### 6.2 OpenCV 桥接
- 自建 XCFramework/静态库，裁剪 `core/imgproc/photo`；BSD 许可在关于页声明。
- Bridge 使用串行队列；禁止多线程同时调用同一 Mat 池。
- C++ 异常统一 catch 并转为 Swift `InpaintError`，禁止异常穿透闪退。
- 输入统一 BGRA8888 或按配置转换；Mat 生命周期由桥接层管理，返回深拷贝或明确所有权。
- 每次调用记录耗时、尺寸、mask 面积，不记录画面内容。

### 6.3 视频管线
- `AVAssetReader` 读取视频轨，输出 BGRA；音频轨通过 reader/writer 透传。
- 视频按源 PTS 写入 `AVAssetWriterInput`，不按帧计数重排。
- `expectsMediaDataInRealTime = false`；等待 `readyForMoreMediaData` 实现背压。
- writer input transform 使用源 transform；方向统一到正方向坐标后再修复。
- VFR 保留源 PTS；可选 30fps 降级时明确重采样策略。
- 音频缺失/多声道/损坏帧：跳过并记录错误码，不中断可恢复流程。
- 取消：cancel reader/writer，finish/cancel writing，清空帧池与临时文件。
- HDR/10-bit：检测 colorPrimaries/transferFunction；不支持则降级 SDR 并提示色差。

### 6.4 图像与 Mask
- 所有 mask 归一化坐标存储；渲染/修复映射到目标分辨率。
- 画笔 pt 转像素按图像显示尺度计算；橡皮擦略大于画笔。
- 透明图：预乘 alpha 处理，RGB 与 alpha 分离修复后正确还原，避免黑边/白边。
- 撤销栈：操作栈 + 定期快照；最大 20 步；内存警告释放快照。
- 瓦片修复：512~1024px，halo 64px，接缝融合后写回。

### 6.5 权限与导出
- 导入使用 PhotosPicker/文件选择；保存使用 add-only 相册权限。
- 导出前检查可用空间 ≥500MB 且 ≥预估输出大小。
- 保存成功防重复点击；失败给出错误码与重试入口。
- 临时文件命名含任务 ID；完成/失败/取消均清理。

## 9. UI/UX 设计规范

### 9.1 视觉系统
- 设计 Token：主色、警示色、成功色、背景色、画布色、mask 高亮色、对比滑杆色。
- 字体：标题/正文/按钮/数值使用统一字号与字重；支持动态字体。
- 间距：8pt 栅格；工具栏、底部操作区、错误提示统一间距。
- 暗色模式：画布、工具栏、弹窗、对比滑杆均适配。
- 横屏：工具栏折叠为图标；画布保持最大区域；底部操作安全区适配。

### 9.2 关键控件
- 模式切换：自动/手动分段控件，当前模式高亮。
- 画笔：粗细滑杆 + 光标预览；橡皮擦图标明确；撤销/重做禁用态可见。
- 选区：控制点可拖动/缩放；多选区可删除；高亮不遮挡画面。
- 对比：左右滑动滑杆 + 双指缩放；滑杆手柄清晰；原图/修复图标签。
- 进度：确定性进度条 + 取消按钮；处理中按钮禁用。
- 空态：未检测到字幕提示手动涂抹；未绘制选区禁止执行。
- 错误态：错误码 + 用户可读文案 + 重试/返回。
- 触觉：执行、撤销、重置、保存成功轻触反馈。

### 9.3 可访问性
- VoiceOver：按钮、滑杆、对比滑杆、进度均有标签。
- 对比度：文字与背景满足可读性；不只靠颜色表达状态。
- 动态字体：不截断关键按钮；必要时横屏/滚动。

3. add-only 相册权限、空间检测、导出失败明确提示。

阶段六：性能、兼容与调试
1. 内存峰值、CPU/GPU、热管理、低端降级。

3. 全页面中文化、可访问性、日志与埋点。
4. 接入 DEBUG 测试调试窗口 View。

## 11. 异常容错机制

1. 素材容错：透明图、横竖屏、损坏素材、超长/超高分辨率视频；损坏提示不闪退。
2. 操作容错：未绘制选区/未检测到字幕禁止执行；提示手动涂抹。
3. 性能容错：低端设备关闭重 AI、降低预览分辨率、降低并发、优先规则修复。
4. 内存容错：监听内存警告，释放预览缓存/撤销快照，必要时暂停任务并提示。
5. 导出容错：add-only 相册权限、存储空间、导出失败原因、临时文件清理。
6. 重复操作容错：修复/导出中锁定按钮；任务 ID 防多线程重复执行。
7. 取消容错：处理中返回/取消需确认；取消后清理帧池、临时文件和 writer。
8. 后台中断：进入后台暂停/取消任务，避免系统终止导致半成品。
9. 模型容错：模型加载失败自动降级规则+Vision/手动，不阻塞。
10. 视频容错：音频缺失、多声道、可变帧率、方向 metadata、损坏帧跳过并记录。
11. HDR/P3 容错：明确降级 SDR/sRGB 并提示；透明图处理预乘 alpha。
12. 状态机容错：`processing/exporting` 中禁止再次执行；`failed` 保留可重试入口。
13. 色彩容错：色彩空间转换失败时回退 sRGB 并提示。
14. 音频容错：音频写入失败时允许“无音频导出”二次确认。

## 12. 状态机与错误码

状态建议：
`idle → importing → detecting → editing → processing → previewing → exporting → completed / failed / cancelled`

规则：
- `processing/exporting` 禁止重复执行与重复导出。
- `cancelled` 必须清理临时文件、帧池、reader/writer。
- `failed` 保留可重试入口与明确错误码。
- 所有异步任务绑定 Task 取消；取消后 5s 内完成清理。
- `importing/detecting` 也支持取消并回到 `idle`。
- 后台中断进入 `cancelled` 或 `failed`，需提示恢复入口。

错误码示例：
- `E1001` 素材不可读
- `E1002` 分辨率/时长超限
- `E1003` 素材方向/元数据异常
- `E2001` 相册权限拒绝
- `E2002` 存储空间不足
- `E3001` 检测失败已降级
- `E3002` 模型加载失败已降级
- `E4001` 修复失败
- `E4002` OpenCV 桥接异常
- `E5001` 导出失败
- `E5002` 音频写入失败
- `E5003` 色彩空间转换失败
- `E5004` 重复导出被拦截
- `E6001` 用户取消
- `E7001` 内存警告暂停
- `E7002` 后台中断
- `E8001` 模型不可用
- `E9001` 视频元数据异常
- `E9002` writer 不可用
- `E9003` 损坏帧跳过记录

## 13. 测试调试窗口 View（仅 DEBUG）

目标：参数调优、故障注入、性能观测、日志导出；不进入 Release。

入口与安全：
- `#if DEBUG` 编译；`FeatureFlags.debugPanelEnabled` 控制。
- 入口：连续点击标题 5 次或长按版本号。
- Release 包不包含入口、调试覆盖层与敏感日志。
- 不保存/导出画面内容，仅导出脱敏元数据与错误码。

呈现方式：
- `DebugPanelView`：`.sheet` 呈现，内部 `NavigationStack`。
- `DebugOverlayView`：`.overlay` 叠加在画布/预览上，可开关。
- `DebugLogView`：独立列表页，按级别/错误码过滤。
- 可选 `.presentationDetents` 使用 iOS 16 可用 API。

功能页签：
1. 参数：Telea 半径、mask 膨胀、羽化、瓦片尺寸/halo、代理分辨率、并发、mask 并集帧数、强制 30fps、输出码率、HDR 降级。
2. 性能：图片 ROI 耗时、视频处理 fps/吞吐、内存峰值、CPU 近似、帧池占用、临时文件大小、当前状态机状态。
3. 故障注入：模拟内存警告、相册权限拒绝、空间不足、模型加载失败、损坏帧、用户取消、writer 失败、音频写入失败、色彩空间失败。
4. 覆盖层：mask 红/绿显示、检测框、ROI 边界、接缝区域、帧时间、并发数、降级标记。
5. 日志：脱敏日志、错误码、任务 ID、取消/清理记录。
6. 导出：通过 `ShareLink` 导出 debug report（JSON/TXT）。

调试文件：
- `DebugPanelView.swift`
- `DebugOverlayView.swift`
- `DebugLogView.swift`
- `DebugSettingsStore.swift`
- `DebugReportExporter.swift`

验收：
- DEBUG 可调参并实时生效；Release 不可见。
- 故障注入可触发对应错误码与兜底提示。
- 导出报告不含画面内容与用户路径敏感信息。

## 15. 验收标准（量化可测）

### 15.1 图片消除
- 基准设备 iPhone 12/13 起，1080P 图片、常规字幕区域、ROI 修复 ≤150ms；不含解码/保存。
- 字幕完全消除，无明显边缘残留、背景断层、过度模糊。
- mask 外像素变化 ≤0.5%；背景区域 SSIM ≥0.98；字幕残留边缘像素占比 <1%。
- 不规则/多行字幕修复人工盲评无可见接缝。
- 手绘边缘无锯齿，橡皮擦微调精准。
- 透明底图片 alpha 正确，无黑边/白边。

### 15.2 视频消除
- 720P/1080P 30fps 短视频无明显掉帧、闪烁、帧错位。
- 1 分钟短视频处理无 OOM、无闪退；内存峰值分设备档位验收。
- 1080P 处理速度 ≥8~10fps，低端设备允许降级。
- 导出保留音频、方向、色彩空间；VFR 可正常播放；音画同步误差 <1 帧。
- HDR 降级有明确提示；音频写入失败有“无音频导出”确认。

### 15.3 智能检测
- 常规底部字幕自动检测：IoU≥0.5 且字幕覆盖率≥95% 视为准确，支持手动微调。
- 非底部字幕可手动涂抹全覆盖。
- 模型不可用/低端设备降级后仍可完成手动流程。

### 15.4 交互体验
- 画笔、橡皮擦、缩放预览流畅无卡顿。
- 撤销、重置、参数调节实时生效。
- 滑动对比无延迟，双指缩放精准。
- 处理中可取消，返回无死页面。
- 画布边缘涂抹与受控返回手势无冲突。
- 处理中不可下拉关闭全屏页。

### 15.5 UI 精致度
- 暗色/横屏布局无遮挡、无截断。
- 空态、加载态、错误态、禁用态完整。
- 画笔粗细预览、对比滑杆、选区控制点清晰可用。
- 触觉反馈与 VoiceOver 标签通过走查。
- 设计 Token 统一，无临时颜色/字号。

### 15.6 工程规范
- iOS 16.0+；`fullScreenCover` 独立页面 + `NavigationStack` 独立导航栈，无导航冲突。
- 左上角返回 + 受控边缘左滑返回可用，且不与画布手势冲突。
- 模块解耦，错误码统一，任务可取消，临时文件可清理。
- DEBUG 测试调试窗口可用，Release 不可见。

### 15.7 容错验收
- 所有异常场景均有友好提示，零崩溃、零无响应。
- 相册权限拒绝、空间不足、损坏素材、模型失败均有明确兜底。
- 重复点击、快速返回、后台切换不产生多任务残留。
- 取消后 5s 内清理临时文件，无后台残留任务。

## 17. 风险清单与规避

1. 导航冲突：全屏页独立 NavigationStack + 自定义返回；处理中禁手势。
2. 手势冲突：GestureCoordinator 仲裁；边缘 20pt 不涂抹。
3. Vision 坐标偏移：统一 CGImagePropertyOrientation。
4. 视频闪烁：时域 mask 并集 + 场景切换清空 + PTS 对齐。
5. 接缝：瓦片 halo + 接缝融合。
6. 透明图黑边：预乘 alpha 正确处理。
7. HDR 偏色：明确降级 SDR 并提示。
8. writer 背压：等待 readyForMoreMediaData，不无界缓存。
9. 取消残留：统一 Task 取消 + 5s 清理验收。
10. 调试泄漏：Release 编译隔离与日志脱敏。

## 18. 最终落地原则

1. 稳定优先：任何 AI 能力失败均可降级到规则+手动。
2. 局部修复优先：只改 mask 区域，无字幕背景不动。
3. 视频流式处理：不缓存全视频，背压限流，保留音频与元数据。
4. 交互闭环：导入、编辑、执行、取消、预览、导出、返回全链路可恢复。
5. 验收分档：性能指标绑定基准设备、分辨率、字幕面积。
6. 调试隔离：测试调试窗口仅 DEBUG 可用，不污染 Release。
7. 实现可证：需求—实现—测试映射齐全后才可标记“功能已实现”。
